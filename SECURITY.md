# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| Current `main` development line | Yes |
| Current GA minor line | Yes, under `SUPPORT.md` |
| `v0.1.0-alpha.1` prerelease | Yes, alpha scope only |
| Earlier revisions | No |

## Reporting a vulnerability

Please use this repository's **Report a vulnerability** control in GitHub's
Security tab. It creates a private report and security advisory for coordinated
disclosure. Do not place vulnerability details, proof-of-concept code, or
affected-system data in a public issue, discussion, or pull request.

Include the affected commit or release, reproduction steps, impact, and any
relevant configuration details. Maintainers will acknowledge a private report
within five business days, provide an initial triage update within ten business
days, and publish an advisory when a fix can be disclosed safely. There is no
bounty program. If a deadline cannot be met, maintainers will provide a status
update through the private report.

## Scope

Report a vulnerability only when it affects Endeavor source, release artifacts,
or the project's supported dependency configuration. Normal parser failures,
feature requests, fixture questions, and unsupported source-format requests
belong in public issues without sensitive details.

Researchers acting in good faith should avoid privacy violations, service
disruption, destructive testing, and access to data beyond what is necessary to
demonstrate the issue.
